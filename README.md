# Проверочка

Первый экран сайта «Проверочка» — сервиса автоматической проверки сайтов на соответствие требованиям законодательства.

## Файлы

Статический сайт без сборки. Все файлы лежат в корне, пути относительные — сайт работает и в корне домена, и в подпапке (например, `/proverochka/` на GitHub Pages).

| Файл | Назначение |
|---|---|
| `index.html` | Страница |
| `styles.css` | Стили |
| `main.js` | Масштабирование иллюстрации проверки, проверка введённого адреса, мобильное меню |
| `favicon.svg` | Иконка сайта |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |

Шрифты подключаются из Google Fonts: Source Serif 4 (заголовок, логотип, цифры отчёта), Fira Sans (интерфейс и текст), Fira Mono (адрес в окне проверки), PT Sans (пример проверяемого сайта).

## Форма проверки

Пользователь вводит домен (префикс `https://` уже показан). Перед отправкой адрес проверяется, и форма уходит методом GET: `./?url=https://example.ru`. Чтобы подключить сервер проверки, замените `action="./"` у формы на адрес обработчика.

## Публикация на GitHub Pages

1. Загрузите все файлы в корень репозитория (без вложенных папок).
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**.
3. Branch: **main**, папка **/ (root)** → Save.
